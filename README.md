## 🚀 A few things I've built

**🌱 CarbonLint - Making code a little greener**

A carbon-aware Python code optimizer that identifies inefficient code, automatically applies optimizations, and compares execution time, memory usage, and estimated CO₂ emissions. Includes a VS Code extension, sandboxed benchmarking, and MCP integration.

**🤝🏽 BridgeUp - Making college feel less lonely**

A Chrome extension and web application that brings peer support directly into Canvas for first-generation college students. Features accountability partnerships, real-time messaging, AI-powered resource recommendations, and personalized academic guidance.

**🧺 Laundry Inventory Management System - Bringing order to laundry chaos**

A full-stack inventory management application designed to streamline laundry operations, manage workflows, and reduce manual administrative work.
